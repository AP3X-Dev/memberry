(2) Run cost booking lives ONLY in finalize_acp_run (spec B names it explicitly; the S16 merge fence allowed only the start-run guard + finalize_acp_run in tasks/runs.py) — inline fallback executor runs (_default_executor/hermes_run_executor terminating via _complete_run/_fail_run) do NOT book cost events; acceptable because ACP worker is the primary production path.
